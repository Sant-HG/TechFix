# 🔧 TechFix — Prototipo web de gestión tecnológica

### Una idea académica llevada a una interfaz funcional con apoyo de inteligencia artificial.

TechFix es un prototipo web desarrollado como parte de un proyecto universitario de Ingeniería de Sistemas. Su propósito es representar de manera sencilla cómo una tienda de tecnología puede organizar sus productos, ventas, citas de servicio técnico y reparaciones mediante una plataforma digital.

El proyecto comenzó con el análisis de una necesidad: muchos establecimientos pequeños y medianos todavía gestionan sus inventarios, solicitudes y servicios de forma manual o mediante aplicaciones de mensajería.

A partir de esta situación, se planteó una solución y se construyó una primera versión visual para explorar cómo podría funcionar.

## 🚀 ¿Qué se desarrolló?

El prototipo cuenta con dos interfaces:

**Panel de administración**
- Visualización y gestión básica del inventario.
- Registro de productos y cantidades.
- Registro de ventas simuladas.
- Organización de citas de servicio técnico.
- Seguimiento del estado de las reparaciones.

**Interfaz del cliente**
- Catálogo de productos disponibles.
- Carrito de compras.
- Simulación de pedidos.
- Solicitud de citas de servicio técnico.
- Consulta básica del estado de reparaciones.

La intención no fue desarrollar un sistema comercial completo, sino representar los procesos principales mediante una interfaz sencilla y comprensible.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura de las páginas.
- **CSS3:** diseño visual y adaptación de la interfaz.
- **JavaScript:** interacciones y operaciones básicas.
- **LocalStorage:** almacenamiento temporal de información en el navegador.
- **GitHub:** publicación y control de versiones del proyecto.

No se implementó una base de datos, un backend ni un sistema de autenticación real.

## 🤖 Inteligencia artificial en el desarrollo

La inteligencia artificial fue una herramienta importante durante la construcción de este prototipo.

Se utilizó para apoyar la generación de código, proponer componentes visuales, estructurar las interfaces y acelerar el paso desde la documentación inicial hasta una demostración navegable.

Mi participación se centró en definir las necesidades del proyecto, establecer su alcance, orientar las funcionalidades, evaluar las propuestas generadas y decidir qué elementos incorporar.

Este proyecto también fue una oportunidad para explorar una forma de trabajo asistida por IA: formular instrucciones claras, revisar resultados y reconocer cuándo una solución necesita simplificarse o mejorarse.

**El objetivo no fue demostrar que todo el código se escribió manualmente, sino experimentar con la IA como herramienta de desarrollo y aprender a dirigir su uso de forma consciente.**

Considero importante ser transparente sobre su participación y diferenciar entre el código generado con asistencia y las decisiones tomadas durante el desarrollo.

## 📌 Estado y limitaciones

**TechFix es una prueba visual y académica, no un producto listo para producción.**

Actualmente:

- No cuenta con autenticación ni permisos seguros.
- La información se almacena localmente en cada navegador.
- Las compras y los pagos son simulados.
- No existe sincronización de información entre diferentes usuarios o dispositivos.
- No se han implementado pruebas de seguridad ni infraestructura de producción.

Estas limitaciones son intencionales y responden al alcance definido para esta etapa.

## 📚 ¿Qué aprendí?

Este proyecto me permitió trabajar en aspectos que van más allá de escribir código:

- Convertir una necesidad en requisitos y funcionalidades concretas.
- Relacionar documentación de software con una interfaz visual.
- Organizar una aplicación desde la perspectiva del administrador y del cliente.
- Utilizar herramientas de IA para acelerar la creación de prototipos.
- Identificar las diferencias entre una demostración funcional y una aplicación preparada para usuarios reales.

## 🔮 Posibles mejoras

Como evolución del prototipo se podrían considerar una base de datos, autenticación de usuarios, gestión centralizada de pedidos y una API para conectar las diferentes funcionalidades.

Estas características no forman parte de la versión actual.
